\section*{Beschreibung unseres Projekts}
In unserem Projekt können Daten über ein spezifisches Schiff dynamisch generiert und dargestellt werden. Um das Projekt zu realisieren wurden folgende Werkzeuge bzw. Techniken verwendet: HTML, cgi-bin, bash-Scripting und gnuplot. Unser Prototyp ermöglicht auf einer Website per dynamisch erzeugtem Dropdownmenü die Auswahl eines Schiffs. Anschließend wird eine Statusseite mit den aktuellen Daten zum Schiff erzeugt. Die Daten umfassen den Namen, die MMSI, den Zielort, die letzte Position sowie die letzte bekannte Geschwindigkeit in Knoten. Die Geschwindigkeiten des letzten Tages werden gleichzeitig per gnuplot erzeugt und unter den genannten Daten angezeigt. Mit einem Klick auf die Koordinaten der letzten Position erfolgt eine Weiterleitung auf openstreetmap.org mit einem Wegpunkt und wird innerhalb des Kartenausschnitts graphisch dargestellt.
